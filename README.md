# 🚀 BuildSphere — Student Project Workspace

**Your Projects. One Workspace.**

BuildSphere is a student project management platform designed to help students organize academic projects, manage tasks and deadlines, collaborate with team members, and track progress through a centralized dashboard.

## 📌 Problem Statement

Students often struggle to manage academic projects because tasks, team members, resources, deadlines, and progress updates are scattered across different platforms. BuildSphere provides a centralized workspace to make academic project management simpler, more organized, and more efficient.

## ✨ Features

- **📊 Interactive Dashboard** — View project statistics, task progress, and upcoming deadlines.
- **📁 Project Management** — Create, edit, organize, and delete academic projects.
- **✅ Task Management** — Create tasks, assign priorities, update statuses, and track completion.
- **👥 Team Collaboration** — Manage team members and organize project responsibilities.
- **📅 Deadline Tracking** — Monitor upcoming deadlines and view project schedules.
- **📚 Resource Management** — Organize project-related resources.
- **🔐 Login & Signup UI** — User-friendly authentication interface with demo functionality.
- **🎨 Responsive Design** — Clean interface designed for desktop, tablet, and mobile devices.
- **🧪 Demo Data Management** — Load sample project data for demonstrations and clear workspace data when needed.

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3, JavaScript
- **Build Tool:** Vite
- **Routing:** React Router
- **Icons:** Lucide React
- **Storage:** Browser localStorage for supported demo data and preferences

## ⚙️ Installation & Setup

### Prerequisites

- Node.js
- npm
- Git (optional)

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Navigate to the project directory

```bash
cd BuildSphere
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 🧪 Demo Usage

1. Open the BuildSphere application.
2. Sign up or use the available demo login flow.
3. Explore the dashboard and project management features.
4. Create projects and tasks to explore the workspace.
5. Use **Load Demo Data** to populate the workspace with sample records, if available.
6. Use **Delete All Data** to clear workspace data after confirming the action, if available.

**Note:** Demo data and authentication behavior depend on the current frontend implementation.
